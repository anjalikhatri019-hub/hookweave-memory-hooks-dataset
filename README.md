# HOOKWEAVE — Checkpointed Memory Hook Scheduling

This is the participant-safe source page for the HOOKWEAVE v5.0.0 synthetic AI-agent memory-hook dataset. The release asset `dataset_public.zip` contains 4,000 training episodes and 1,000 test episodes, each with 360 events. Solvers schedule a public budget of one to three hooks across three checkpoints and report the stored values and evidence after each checkpoint. Six queried slots and 12 shuffled candidates make execution time and partial trajectories matter. All checkpoint goals are public; the training oracle is one example of an optimal schedule.
